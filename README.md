# 🚀 Gerador de Currículos Online (APO - Fundamentos de Programação para Internet)Gerador de Currículos Online desenvolvido como Atividade 

Visão Geral:

Este projeto é a Atividade Prática Orientada (APO) para a disciplina de Fundamentos de Programação para Internet , com o objetivo de criar uma aplicação web que gere currículos. O desenvolvimento busca aplicar os conceitos de programação web, design responsivo e versionamento.





Tecnologias Utilizadas:


Backend: PHP 



Frontend: HTML, CSS, JavaScript, jQuery 






Frameworks Visuais: Bootstrap / Tailwind (conforme escolha na implementação) 



Ambiente de Desenvolvimento: Xampp 


Versionamento: Git e GitHub 


Funcionalidades Principais:

Interface de formulário para coleta de dados pessoais e profissionais.


Cálculo automático da idade via JavaScript.

Inclusão dinâmica de campos (Experiências, Referências) usando JavaScript e/ou jQuery.

Formatação e geração final do currículo utilizando PHP.

Opção para download/impressão do currículo gerado (window.print()).
